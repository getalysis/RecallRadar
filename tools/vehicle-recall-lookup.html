How This Works

This tool queries NHTSA's public recall API directly and in real time — it is not limited to RecallRadar's daily-updated database, so it reflects the very latest open recalls on file with NHTSA at the moment you search.

FAQ

Is this official NHTSA data?

Yes — results come directly from NHTSA's public recalls API in real time. RecallRadar does not modify or filter the results.

What if my exact model isn't found?

Try the closest official model name (e.g. "F-150" instead of "F150", "3 Series" instead of "328i"). NHTSA indexes recalls by model family, not by trim.

Does this need my VIN?

No — this lookup uses make/model/year only. A VIN-specific check can catch recalls tied to a specific manufacturing batch and is available directly at nhtsa.gov/recalls.
